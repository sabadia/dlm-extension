## Firefox

- `strict_min_version` is **140.0**: that is where `data_collection_permissions` is understood on desktop (Android 142).
  We declare `{ "required": ["none"] }`: we collect nothing. `web-ext lint` is clean of errors with these.
- Host access in MV3 is opt-in. From Firefox 127 the install prompt asks for it, and the user can switch "access to
  all websites" off later in the add-on's permissions. The spike's temporary install had it, and `permissions.contains`
  reported `<all_urls>`. **The extension must check `permissions.contains` and show a "grant access" state** when it
  is missing (E5.3).
- **Listeners are registered at load.** In an event page a `webRequest` listener added after an `await` did not fire; at
  top level it did (see E0.7).

## Chrome

- Host access is granted at install. `<all_urls>` triggers a human review in the Chrome Web Store (E9), so the
  justification is written down now (docs/PLAN.md, "Permissions").
- The branded Chrome ignores `--load-extension`, so developers load the unpacked build from `chrome://extensions`.

## Minimum permission set (each justified)

| Permission               | Why                                                                  |
| ------------------------ | -------------------------------------------------------------------- |
| `downloads`              | see, cancel and erase browser downloads; start the fallback download |
| `webRequest`             | response headers for downloads and media (observe only)              |
| host access `<all_urls>` | `webRequest`, cookies and the daemon on any address                  |
| `cookies`                | the download's own cookies                                           |
| `storage`                | settings and the token (local only)                                  |
| `nativeMessaging`        | find and pair with the local app                                     |
| `contextMenus`           | "Download with DLM"                                                  |
| `notifications`          | link expired, errors                                                 |
| `alarms`                 | 30 s wake-up to watch for a link to refresh                          |
| `activeTab`, `scripting` | the page scan on demand                                              |
